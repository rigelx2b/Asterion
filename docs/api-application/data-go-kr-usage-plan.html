2. 활용 목적

국내 상장주식의 일별 시세를 이용하여, 여러 미래 거래일(1·3·5·10·20거래일 후) 수익률의 방향성과 크기를 예측하는 시계열 모델을 연구합니다. 연구는 Rust 언어로 구현하며, 다음을 검증하는 것이 목적입니다.

  • 데이터 정합성 검사(결측·중복·이상치, 거래일 정렬) 방법
  • 미래 정보 누수 없이 학습·검증·평가 기간을 시간순으로 분리하는 평가 체계
  • 단순 기준 모델과 딥러닝 모델의 예측 성능 비교

본 연구는 투자 자문, 매매 신호 제공, 유료 서비스 등 상업적 목적에 사용하지 않습니다.

3. 활용 데이터 및 범위

상세기능주식시세 (그 외 상세기능은 사용하지 않음)
대상 종목KOSPI·KOSDAQ 시가총액 상위 보통주 약 20개 종목으로 시작하며, 연구 진행에 따라 최대 수백 종목까지 확대할 수 있음
대상 기간API가 제공하는 기간 내 과거 일별 시세 및 이후 매 영업일 신규 시세
사용 항목기준일자, 단축코드, 종목명, 시장구분, 시가·고가·저가·종가, 거래량, 거래대금, 상장주식수, 시가총액
주요 요청변수serviceKey, resultType(json), likeSrtnCd, beginBasDt, endBasDt, numOfRows, pageNo

4. 데이터 처리 흐름

  • 수집: 종목·기간 단위로 조회하고, 페이지당 최대 행 수를 사용하여 호출 수를 최소화합니다.
  • 원본 보관: 응답 원문을 개인 PC에 캐시로 저장하여 같은 데이터를 다시 요청하지 않습니다.
  • 검증: 가격 정합성(저가 ≤ 시가·종가 ≤ 고가), 중복·결측 거래일, 비정상 변동을 검사합니다.
  • 분석: 검증된 데이터로 수익률 지표를 계산하고 예측 모델을 학습·평가합니다. 모든 처리는 개인 PC 안에서만 이루어집니다.

5. 호출량 계획

초기 과거 데이터 수집1회성. 종목당 수 건 이내 (예: 20종목 기준 약 100건 이내)
일상 갱신데이터 갱신(영업일 다음날 오후 1시 이후) 후 1일 1회, 수십 건 이내
호출 제어요청 간 최소 간격을 두고, 오류 시 재시도 횟수를 제한하며, 인증·요청 오류(4xx)는 재시도하지 않음. 개발계정 트래픽 한도 이내로 운영

6. 이용허락범위(제4유형) 준수 방안

  • 출처표시: 연구 결과물과 소스 코드 문서에 「출처: 금융위원회, 공공데이터포털(data.go.kr)」을 표기합니다.
  • 상업적 이용금지: 데이터와 그 분석 결과를 판매·유료 제공하거나 영리 서비스에 사용하지 않습니다.
  • 변경금지: 원 데이터를 수정·가공하여 배포하지 않습니다. 원본과 가공 데이터 모두 개인 PC에만 보관하며, 공개 소스 저장소에는 데이터 파일을 올리지 않도록 설정합니다(.gitignore로 데이터 폴더 제외).
  • 제3자 제공 금지: 데이터 원문이나 데이터 파일을 제3자에게 제공하지 않습니다.

7. 인증키 관리 및 보안

  • 인증키는 소스 코드에 넣지 않고, 개인 PC의 환경변수(로컬 .env 파일)에서만 읽습니다.
  • .env 파일은 버전관리 대상에서 제외되어 외부 저장소에 올라가지 않습니다.
  • 로그와 오류 메시지에 요청 URL을 남길 때 인증키 부분을 가립니다(예: serviceKey=****).
  • 인증키가 노출된 것으로 의심되면 즉시 재발급을 요청합니다.

부록. API 호출 스크립트 (예시)

실제 연구 코드에서 사용할 호출 방식의 요약입니다. 인증키는 환경변수에서 읽으며 코드와 문서에 포함하지 않습니다.

(1) 요청 형식

GET https://apis.data.go.kr/1160100/GetStockSecuritiesInfoService_V2/getStockPriceInfo
    ?serviceKey=****            (환경변수에서 읽음, 로그에서는 가림)
    &resultType=json
    &likeSrtnCd=005930          (종목 단축코드)
    &beginBasDt=20240101&endBasDt=20241231
    &numOfRows=1000&pageNo=1

(2) Rust 호출 코드

use std::{env, fs, time::Duration};

const ENDPOINT: &str =
    "https://apis.data.go.kr/1160100/GetStockSecuritiesInfoService_V2/getStockPriceInfo";

/// 로그·오류 메시지에 남기기 전에 인증키를 가린다.
fn redact(text: &str, key: &str) -> String {
    text.replace(key, "****")
}

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // 인증키는 로컬 .env / 환경변수에서만 읽는다 (저장소에 포함하지 않음).
    let key = env::var("DATA_GO_KR_SERVICE_KEY")?;
    let client = reqwest::Client::builder()
        .timeout(Duration::from_secs(30))
        .build()?;

    for code in ["005930", "000660"] {
        let cache = format!("data/raw/data_go_kr/{code}_2024.json");
        if fs::metadata(&cache).is_ok() {
            continue; // 이미 받은 데이터는 다시 요청하지 않는다.
        }

        let resp = client
            .get(ENDPOINT)
            .query(&[
                ("serviceKey", key.as_str()),
                ("resultType", "json"),
                ("likeSrtnCd", code),
                ("beginBasDt", "20240101"),
                ("endBasDt", "20241231"),
                ("numOfRows", "1000"),
                ("pageNo", "1"),
            ])
            .send()
            .await;

        match resp {
            Ok(r) if r.status().is_success() => fs::write(&cache, r.text().await?)?,
            Ok(r) => eprintln!("{code}: HTTP {} (재시도하지 않음)", r.status()),
            Err(e) => eprintln!("{code}: {}", redact(&e.to_string(), &key)),
        }

        // 요청 사이에 간격을 두어 서버 부하와 트래픽 한도를 지킨다.
        tokio::time::sleep(Duration::from_millis(500)).await;
    }
    Ok(())
}
